# Career Copilot Agent MVP 演示

## 1 分钟录屏结构

0-10秒：展示首页与项目说明 / Agent 架构模块，说明项目定位是 AI 求职投递 Agent，当前版本为 V2.2：Agent MVP Showcase。

10-20秒：进入「交互工作台 Demo」里的「Agent 联调」标签，说明前端会调用本地 FastAPI 后端 `/api/agent/run`。

20-35秒：点击「填充联调样例」，再点击「一键运行 Career Copilot Agent」，展示 JD 输入、简历摘要、作品集链接和任务目标。

35-50秒：展示结构化输出区域，依次扫过 JD解析、简历匹配、优先级判断、材料生成、质量审核和下一步行动建议。

50-60秒：点击「保存本次分析」，再点击「导出 Markdown 报告」，说明结果可以沉淀到 LocalStorage，也可以导出为可复盘报告。

## 面试讲稿

我这个项目不是一开始就做 Agent，而是先用静态 Demo 验证求职投递的核心流程，包括 JD 解析、简历匹配、材料生成和投递管理。之后我把流程拆成 JD 解析、简历匹配、投递优先级判断、材料生成和质量审核五个 Skill，再用 FastAPI 后端封装成 `/api/agent/run` 的 Agent 工作流。

前端新增 Agent 联调面板，调用真实接口并渲染结构化结果。V2.1 版本进一步加入输出评估、保存分析和 Markdown 报告导出，让 Agent 的结果可以沉淀和复盘。V2.2 版本则把项目包装成作品集展示形态，补充升级路径、架构图、工作流图、Agent 说明和质量评估方法，让面试官能快速看懂我为什么做这个项目、Agent 如何工作，以及这个项目体现了哪些 AI 产品能力。
